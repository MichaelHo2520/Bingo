# 🎉 派對遊戲 ｜ 十二款多人連線遊戲（Online Multiplayer Party Games）

一個網址、**十二款遊戲**：賓果、五子棋、數獨、麻將消消樂、台灣 16 張麻將、排七、大老二、台式 21 點、UNO、象棋暗棋、成語接龍、你畫我猜。

> 適合：家庭聚會、朋友同樂、公司尾牙 / 團康、課堂帶動、直播互動。

## ✨ 全部遊戲共通的功能

### 🌐 連線對戰

- **開房 / 加入超簡單**：建立房間後，朋友從房間列表**一鍵加入**，不必記房號、不必註冊。
- **首頁看得到誰在玩**：主選單上方會顯示「現在有人在玩」的房間，遊戲卡也依**實際被玩過的場數**排序。
- **斷線自動復原**：切到別的 App、短暫斷網都不會掉出房間，回來自動歸位、分數不歸零。
- **房主管理**：可以移出玩家、重設戰績、開新一輪。
- **連玩多局計分**：多數遊戲會累積勝場 / 分數排行，一玩就是一整晚。

### 💬 即時互動

- **互動表情**：對全場或指定某人送出表情，畫面上會飛出來。
- **一句話訊息**：內建罐頭短語（「加油～」「穩住穩住」「太扯了 😂」…），也能自己打字。
- **語音留言**：現場錄一段送給全房，還能**自訂自己的語音**。

### 🎯 一個人也能玩

十二款裡有十一款可以單機遊玩，其中七款（五子棋、台灣麻將、排七、大老二、台式 21 點、UNO、象棋暗棋）配有**電腦對手**，其餘是單人解謎 / 練習；五子棋還能兩個人**輪流點同一支手機**下。安裝成 App 後**離線也能玩**。

### 🎨 個人化與體驗

- **五種主題**配色，設定會自動記住。
- **音效 · 背景音樂 · 語音音量**分別可調，背景音樂可選曲目。
- **輪到你時震動**（連線 · 手機）。
- **「大 / 小」** 一鍵收掉周邊 UI，把棋盤 / 牌桌 / 畫板放到最大。
- **全螢幕模式**：適合投影到大螢幕帶全場玩。
- **PWA**：可「加到主畫面」像 App 一樣開，並支援離線遊玩。

## 🕹️ 怎麼開始

1. 打開網頁，從主選單挑一款遊戲。
2. 選 **🌐 連線對戰**：輸入暱稱 → **建立房間**，或直接從列表**加入朋友的房間**。
3. 或選 **🎮 單機遊玩**：一個人跟電腦或自己玩（你畫我猜沒有這個選項）。
4. 房主決定規則、大家按「準備好了」，開始！ 🎉
